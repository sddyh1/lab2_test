# TriangleLab — Unit Testing

Проект демонстрирует модульное тестирование класса `TriangleCalculator`, который определяет тип треугольника по трём сторонам и вычисляет координаты вершин для визуализации.

## 📌 Структура репозитория

- `TriangleLab/` — основной проект с реализацией
- `TriangleLab.Tests/` — проект с модульными тестами NUnit

## 🚀 Быстрый старт

1. Клонируйте репозиторий.
2. Восстановите NuGet-пакеты:
   - Основной проект: `Serilog`, `Serilog.Sinks.Console`, `Serilog.Sinks.File`
   - Тестовый проект: `NUnit`, `NUnit3TestAdapter`, `Microsoft.NET.Test.Sdk`
3. Соберите решение.
4. Запустите тесты: `dotnet test` или через Test Explorer в Visual Studio.

## ✅ Результаты

После исправления трёх дефектов в исходном коде:

- **Все 27 тестов успешно проходят.**
- Время выполнения: < 1 секунды.

## 🐛 Найденные дефекты и исправления

### 1. Отсутствие проверки на `null`
Метод падал с `ArgumentNullException` при передаче `null` в `float.TryParse`.
**Решение:** явная проверка аргументов на `null` в начале метода.

### 2. Некорректная обработка `Infinity` и `NaN`
Строка `"Infinity"` успешно парсилась, нарушая дальнейшие вычисления.
**Решение:** добавлена фильтрация `float.IsInfinity` и `float.IsNaN` после парсинга.

### 3. Опасное извлечение квадратного корня
Выражение `b*b - xC*xC` могло стать отрицательным из-за погрешностей `float`, что приводило к `Math.Sqrt(-) => NaN`.
**Решение:** применение `Math.Max(0, value)` перед `Sqrt`.
