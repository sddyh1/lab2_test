TriangleLab: модульное тестирование
В этом проекте показано, как писать модульные тесты для класса TriangleCalculator. Этот класс определяет тип треугольника по трём заданным сторонам и вычисляет координаты вершин (для последующей отрисовки).

 Что внутри
TriangleLab/ — основная библиотека с логикой расчёта.

TriangleLab.Tests/ — набор модульных тестов на базе NUnit.

 Как запустить
Скопируйте репозиторий к себе.

Установите NuGet-пакеты:

Для основного проекта: Serilog, Serilog.Sinks.Console, Serilog.Sinks.File

Для тестов: NUnit, NUnit3TestAdapter, Microsoft.NET.Test.Sdk

Соберите решение.

Запустите тесты: dotnet test или через меню Test Explorer в Visual Studio.

 Итоговый результат
После исправления трёх ошибок в коде:

Все 27 тестов проходят успешно.

Время выполнения — меньше секунды.

 Какие ошибки были найдены и как их поправили
Отсутствие проверки на null
Раньше метод падал с ArgumentNullException, если в него передавали null.
Исправление: добавили явную проверку аргументов в начале метода.

Неправильная обработка Infinity и NaN
Строка "Infinity" спокойно парсилась и ломала дальнейшие расчёты.
Исправление: после парсинга добавили фильтрацию float.IsInfinity и float.IsNaN.

Риск отрицательного значения под квадратным корнем
Из-за погрешностей float выражение b*b - xC*xC иногда становилось чуть меньше нуля, и Math.Sqrt возвращал NaN.
Исправление: перед вызовом Sqrt применяем Math.Max(0, значение).
